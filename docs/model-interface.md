# ONNX 模型输入输出

每次路线测试开始时，模型的记忆清零。每段视频开始时，识别模型的记忆也清零。

数组最前面的 `1` 表示一次处理一个样本。记忆区的 `N` 是模型要保存多少个数，导出时固定为 1 至 8192 之间的整数，输入输出大小一致。例如需要保存 265 个数，就把 `N` 设为 265；两个模型可以使用不同的大小。图像按 RGB 排列，数值除以 255，变为 0 至 1。完整字段表也保存在 `challenges/v2/model_interface.json`。

## 1. 导航和运控模型 policy.onnx

### 输入

| 名称 | 类型和大小 | 内容 |
|---|---|---|
| `front_rgb` | float32 `[1,3,144,256]` | 前置相机画面，必填 |
| `instructions` | int64 `[1,11]` | 去程 5 条、掉头 1 条、返程 5 条指令，必填 |
| `imu` | float32 `[1,6]` | 前三项为机身角速度，后三项为机身坐标下的单位重力方向，可选 |
| `joint_position` | float32 `[1,16]` | 关节位置，弧度，可选 |
| `joint_velocity` | float32 `[1,16]` | 关节速度，弧度/秒，可选 |
| `previous_action` | float32 `[1,16]` | 上次输出的动作，可选 |
| `memory` | float32 `[1,N]` | 模型上次留下的记忆，可选 |

指令编码：`1` 左转，`2` 直行，`3` 右转，`4` 掉头。模型从前置画面发现路口，确认这是新路口后，取出对应的左转、直行或右转指令。完成转向并离开后，再计入下一个路口。

### 输出

| 名称 | 类型和大小 | 内容 |
|---|---|---|
| `action` | float32 `[1,16]` | 关节动作，范围 −1 至 1 |
| `memory_out` | float32 `[1,N]` | 留给下一次调用的记忆；使用 `memory` 时提供 |

前 12 项依次为左前、右前、左后、右后的三个腿关节：髋横摆、髋前后摆、膝关节。最后 4 项依次是这四个轮子。

腿动作按 `默认角度 + 动作 × 缩放值` 转成位置目标；每条腿的缩放值是 `0.25、0.6、0.8` 弧度。轮子动作乘以 35，转成弧度/秒。默认角度和关节名称见 `challenges/v2/robot/control.json`。

物理计算每秒 200 次，模型每秒调用 50 次，相机每秒更新 10 次。每次调用最多使用 0.5 秒；超时或输出无效动作时，本次运行停止。

## 2. 识别模型 reader.onnx

### 输入

| 名称 | 类型和大小 | 内容 |
|---|---|---|
| `image` | float32 `[1,3,360,640]` | 当前视频画面，必填 |
| `memory` | float32 `[1,N]` | 上一帧留下的记忆，可选 |

可以使用记忆，把前几帧的信息留到下一帧。

### 输出

每帧最多输出 16 个标牌：

| 名称 | 类型和大小 | 内容 |
|---|---|---|
| `boxes` | float32 `[1,16,4]` | 每个标牌的左、上、右、下坐标，除以图像宽高，范围 0 至 1 |
| `tokens` | int64 `[1,16,16]` | 每个标牌最多 16 个字符编码 |
| `kinds` | int64 `[1,16]` | `0` 空位，`1` 普通数字，`2` 温度 |
| `confidence` | float32 `[1,16]` | 可信度，0 至 1 |
| `readable` | bool `[1,16]` | 是否看得清 |
| `memory_out` | float32 `[1,N]` | 留给下一帧的记忆；使用 `memory` 时提供 |

字符编码：`0` 结束，`1` 至 `10` 对应数字 `0` 至 `9`，`11` 是负号，`12` 是小数点，`13` 是正号。

例如 `00127` 编为 `[1,1,2,3,8,0,...]`。温度的 `C` 由 `kinds=2` 表示，字符里填写数值。

没有标牌的空位写 `kinds=0`。看不清的标牌仍填写位置、类别和可信度，`readable=False`；运行程序会把它写成“看不清”的结果。

每帧推理最多使用 0.5 秒。

## 3. 先检查导出格式

```bash
python -m xunyuan_eval check-submission --submission my_team/submission.json
```

需要看一组文件样例时，可以运行：

```bash
python -m tools.make_v2_interface_example --output artifacts/interface_example
```

生成的导航模型输出零动作，识别模型输出空结果，用来检查模型文件、运行和记录步骤。

使用 PyTorch 导出时可设置 `external_data=False`，把权重写进同一个 ONNX 文件。

S10 基础程序可从云深处官方的 [SDK](https://github.com/DeepRoboticsLab/sdk_deploy) 和[训练代码](https://github.com/DeepRoboticsLab/rl_training)获取。

# 推力和地面摩擦怎样实测

本轮最高评分档为 **60 N，侧推持续 0.5 秒**，随后测 40、20、5 N。使用本机训练过的 S10 控制模型，在仓库的 MuJoCo 机器人与执行器配置下测得。

## 1. 测试条件

- 机器人总质量约 18.99 千克。
- 前进速度指令为 0.4 米/秒。
- 左右两个方向，各在行走 2.5、3.0、3.5 秒开始推，共六次独立运行。
- 每次重新初始化机器人和模型历史；持续侧推 0.5 秒，观察至 7 秒或倾倒。
- 推力从 200 N 开始向下扫描，包含 200、160、120、100、80、60、40、20、5、0 N。

无推力六次对照均通过。40 N 六次通过，60 N 六次失败，因此把 60 N 选作本轮最高评分档。完整记录在 `challenges/v3/calibration.json`，包括模型校验值、各次倾斜角、横向偏移、施力方向和原始轨迹校验值。

这个校准检查的是行走控制器受到侧推后的反应；正式测评还需要完成五张地图上的规定路线并返回。

## 2. 检查力确实生效

另外把机器人放到空中，排除地面摩擦的影响，施加同样的推力和持续时间，测量整机质心速度变化，与 `推力 × 时间 ÷ 总质量` 比较。

四档均核对通过。正式评分还逐物理步检查三次推力是否完整施加。

```bash
python -m tools.check_v3_physics --output results/physics_check.json
```

这条命令同时检查五张图的雷达点云、墙体碰撞和四档实际地面摩擦。

## 3. 检查摩擦确实改变

四档摩擦系数为 0.1、0.2、0.4、0.8。程序调整接触双方的参数，然后直接读取 MuJoCo 当前接触的系数；四档均与目标值一致。

直行基线在这四档均能完成短距离行走。进一步用相同的 40 N 侧推核对地面差别，左右各一次，测得最大横向偏移如下：

| 实际摩擦系数 | 最大横向偏移范围 |
|---|---|
| 0.1 | 0.386 至 0.495 米 |
| 0.2 | 0.238 至 0.257 米 |
| 0.4 | 0.120 至 0.173 米 |
| 0.8 | 0.060 至 0.078 米 |

这组对照用于核对变滑后的实际反应。正式摩擦评分单独运行，不加侧推，覆盖整条路线、路口转向、掉头和返回。

接触参数的合并规则见 [MuJoCo 官方说明](https://mujoco.readthedocs.io/en/stable/modeling.html#contact-parameters)。

## 4. 换模型重新校准

安装校准工具所需的 ONNX 依赖后，传入对应模型和元数据：

```bash
python -m pip install -e ".[runtime,onnx]"
python -m tools.calibrate_disturbance \
  --policy path/to/model.onnx --metadata path/to/model.json \
  --output results/new_calibration
python -m tools.build_challenge_v3 \
  --calibration results/new_calibration/calibration.json \
  --output results/new_challenge
```

本校准适配器对应 `s10-v7-53` 控制器，元数据说明 265 维历史观测和 16 个动作的排列。选手正式提交仍使用自己的运行代码和权重格式。

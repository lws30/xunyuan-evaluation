# v0.1 开发评分口径

此配置依据巡渊参赛指导的整理口径实现，状态为 `candidate_rules_not_frozen`。正式发布比赛规则前须完成场景与实机试测，再冻结规则版本。

## 独立通行

7 类、各 3 次，共 21 次。直道/转弯合为 6 次、上下坡合为 6 次，上楼梯、下楼梯、摩擦变化分别 3 次，共五组，每组满分 5 分。不保留旧版独立 M07 外力测试。

每个试次需满足：

- 初始整机外廓尚未完全越过出口。
- 时限内整机外廓从出口后方完全通过有宽度限制的出口门。
- 记录完整，没有禁止接触、越界、非法动作、人工接管或超过候选倾角阈值。
- 实际以 `completed` 正常结束，而不是超时或崩溃。

这意味着完成标志本身不足以得分；只让机身中心过线、抄旁路越过无限平面、删除未完成试次，都不会获得完整分数。

## 连续导航

三轮共 15 个导航事件。根据相邻状态样本线段与有向有限出口门的交点复算选择。只按当前有效导航事件处理出口，不能提前经过未来目标就得分。

第一次走错出口，该事件得 0 分。自主折返、再穿越正确出口后可以继续后续任务，但已失分不恢复。回收事件位于顺序最后，不能跳过前序路线直接触发。此处“顺序到达”与“首次选择正确”分别记录。

## 到点停靠

三轮共 12 个事件。默认候选阈值：

| 条件 | 阈值 |
|---|---:|
| 水平位置误差 | ≤ 0.15 m |
| 要求朝向的航向误差 | ≤ 10°，按角度环绕计算 |
| 实际水平速度 | ≤ 0.03 m/s |
| 实际偏航角速度 | ≤ 0.05 rad/s |
| 连续保持时间 | ≥ 2 s |
| 单轮时限 | 600 s |

停靠窗口还必须处于对应前序导航门到达之后、下一段导航门到达之前。去程和返程同名站点使用不同事件窗口。速度、姿态越限或采样中断都会打断连续保持。

## 安全、超时与缺失

候选跌倒判据为横滚或俯仰绝对值超过 45°；这属于待冻结的安全参数，不是厂商硬件能力结论。禁止接触连杆清单、完整通行外廓、标准负载、初态、扰动适用范围与时限仍需要赛事方统一冻结。

连续任务遇到第一个安全违规、超时或遥测缺口时，评分截断到此前有效样本；此前已完成事件保留，之后事件得 0 分。无效的时间戳、字段或 JSON 属于格式错误，命令返回明确错误。

## 人工项与读数诊断

自动分固定为 70。初赛报告 30 分待人工；决赛巡检记录回看 25 分、部署复现 5 分待人工。文件存在不等于记录质量合格，因此本工具不以“有视频路径”自动发放这 25 分。

读数诊断采用精确数字字符串、温度容差和明确拒识。它不额外计入 100 分总表，也不启用旧版识别/物理测温权重。

# 评分规则

这里列出 v0.1.1 随附的练习规则。具体参数保存在 `references/public_dev_v3_candidate.json`。

## 通行

共 21 次测试，分成直道与转弯、上下坡、上楼梯、下楼梯、摩擦变化五组。每组满分 5 分，总分 25 分。

一次测试通过，需要满足：

- 开始时，机器人还有一部分在出口线后面。
- 在规定时间内，整台机器人从指定出口通过。
- 过程中的姿态、接触、行驶区域和动作符合要求，记录连续。
- 测试正常结束，`termination` 为 `completed`。

通过出口时，机器人所有碰撞部件都要越过出口线，并处于出口宽度内。

## 导航

三轮共 15 次路口选择，满分 25 分。

评分器按任务顺序检查机器人穿过的出口，并记录每个路口第一次选了哪里。第一次选对就得分；第一次选错，该路口得 0 分，折返后可以继续后面的任务。

出口在规则文件中写明位置、方向和宽度。机器人沿指定方向穿过出口时，算一次有效通过。

## 停靠

三轮共 12 次停靠，满分 20 分。每次需要同时满足下面的条件，连续保持至少 2 秒：

| 条件 | 要求 |
|---|---:|
| 离目标点的水平距离 | ≤ 0.15 m |
| 朝向误差 | ≤ 10° |
| 实际水平速度 | ≤ 0.03 m/s |
| 实际转向速度 | ≤ 0.05 rad/s |
| 连续保持时间 | ≥ 2 s |

停靠要在到达对应路口之后、经过下一段路口之前完成。去程和返程分别计分。任何一项超限或记录中断，保持时间就重新计算。

## 摔倒、超时和记录中断

机器人向左右或前后倾斜超过 45°，按摔倒处理。评分器还检查禁止接触、越界、动作违规和人工接管。连续任务每轮限时 600 秒。

V3 配置要求每 0.005 秒记录一次状态，最大允许间隔为 0.0075 秒。超过这个间隔，按记录中断处理。

独立通行测试发生问题时，该次不通过。连续任务发生问题时，保留问题发生前已完成的有效成绩，之后的项目计 0 分。

少跑的测试按 0 分计算，总次数保持不变。缺少字段、时间顺序错误或文件格式错误时，程序会指出错误。

## 人工评审和图片识别

自动评分满分 70 分，其余 30 分由人工评审：

| 阶段 | 人工评审内容 |
|---|---|
| 初赛 | 方案报告 30 分 |
| 决赛 | 巡检记录回看 25 分，部署与复现 5 分 |

数字和温度图片识别单独统计正确数。数字按字符串比较，温度默认允许 0.1 ℃ 误差；看不清的图片应填写原因。

## 怎么增加难度

可以在规则文件里缩短时限、收窄出口、减小停靠允许误差，或延长停稳时间。坡度、台阶高度和地面摩擦需要在仿真场景中修改，并配好对应的出口和停靠点。

每套配置使用一个新的 `reference_id`，方便区分不同难度的成绩。增加测试次数或评分项目时，要同时修改评分程序中的次数和分值。

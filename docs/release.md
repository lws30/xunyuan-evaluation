# 版本说明

## v0.2.0

- 分数调整为导航运控 50（路线 30、扰动 20）、视频识别 20、报告 30。
- 提供五张带 T、Y 路口的 MuJoCo 赛道，以及去程和返程任务。正式测试可随机调整直道路段长度。
- 用轨迹偏离程度扣分；碰撞、摔倒和越界时结束本次运行。
- 扰动按 0.5、1、3、5 牛递增测试，保留已通过档位的分数。
- 提供十段 10 分钟的右侧相机视频，8 段训练、2 段测试，包含小标牌、模糊和遮挡。
- 选手提交 `policy.onnx`、`reader.onnx`、`report.pdf` 和 `submission.json`。
- 增加模型检查、模型打包、MuJoCo 运行、视频识别、成绩计算和填写报告分的命令。

使用方法见[首页](../README.md)，扣分表见[评分规则](rules.md)。

# 发布与复核说明

## 公开内容

本仓库公开评分实现、通用遥测记录器、MuJoCo 采样适配器、公开开发几何参考、合成协议样例、数字与温度读屏图片、测试和文档。

## 版本与正式评测

发布版本为 0.1.1，遥测协议为 1.0。参考配置有独立 `reference_id` 与状态字段。任何影响分母、判据、阈值和场景坐标的调整都应更新参考标识，并以发布说明通知选手。

正式裁判可复用同一评分函数，但必须使用赛事方采集的轨迹和正式参考文件。正式隐藏参考配置不放在本公开仓库。自评记录包不能替代算法镜像，也不能直接作为官方成绩来源。

## v0.1.1 更新

- 第七节说明运行依赖、仿真状态来源、跌倒判据和实际测试范围。
- 增加 12 张数字与温度面板、完整温度数据标注和 30 条温度图片样例。完整 15,000 条温度样本及其 30,000 张图片通过 Release 附件提供，详见[数据集说明](datasets.md)。
- 增加 `reading-reference`，将温度图片标注转换为现有读数诊断接口所需的参考文件。
- 增加 MuJoCo 重力倾倒检查，验证物理步进、状态记录与跌倒判定。

## 测试范围

核心测试覆盖协议、评分、读数诊断、数据集接入和打包；可选适配器测试覆盖 MuJoCo 状态读取；物理步进检查使用简单刚体。完整 S10 赛道运行需要另行接入对应模型、场景和控制策略。

多版本 Python CI 模板保存在 `docs/ci-workflow.example.yml`，可放入 `.github/workflows/test.yml` 启用 GitHub Actions。
